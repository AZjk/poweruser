usage: fast_G2_average.py [-h] [-o OUTPUT] [--baseline-min BASELINE_MIN] [--baseline-max BASELINE_MAX] [--baseline-qindex BASELINE_QINDEX]
                          [--baseline-window BASELINE_WINDOW] [--num-workers NUM_WORKERS] [--cache-mb CACHE_MB] [--verbose] [--precision {single,double}]
                          flistname

Average G2 data from HDF files using a shared-memory map-reduce strategy.

positional arguments:
  flistname             A text file with a list of input HDF files (one per line).

options:
  -h, --help            show this help message and exit
  -o OUTPUT, --output OUTPUT
                        Output file name. (default: averaged_results.hdf)
  --baseline-min BASELINE_MIN
                        Minimum g2 baseline to include file. (default: 0.95)
  --baseline-max BASELINE_MAX
                        Maximum g2 baseline to include file. (default: 1.35)
  --baseline-qindex BASELINE_QINDEX
                        Q index for baseline calculation. (default: 0)
  --baseline-window BASELINE_WINDOW
                        Window size for baseline calculation. (default: 3)
  --num-workers NUM_WORKERS
                        Num worker processes (default: physical cores). (default: None)
  --cache-mb CACHE_MB   HDF5 raw chunk cache per worker (in MB). (default: 512)
  --verbose             Enable detailed, per-file diagnostic logging (DEBUG level). (default: False)
  --precision {single,double}
                        Processing precision for accumulation (default: single). (default: single)
